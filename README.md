# Alpha Hunter 🎯

An AI-powered crypto alpha agent built with ElizaOS and deployed on Nosana's decentralized GPU network.

## What it does
- Tracks trending tokens before they pump
- Finds upcoming airdrops and whitelist opportunities  
- Monitors whale wallet movements
- Surfaces new crypto narratives early
- Gives actionable insights via simple chat

## Tech Stack
- ElizaOS v1.7.2
- Nosana Decentralized GPU Network
- Qwen3.5-27B inference model

## Setup
1. Clone this repo
2. Copy .env.example to .env and fill in your values
3. Run: pnpm install
4. Run: pnpm run dev
5. Open http://localhost:3000

## Usage
Ask Alpha Hunter anything:
- "What's trending in crypto today?"
- "Any good airdrops coming up?"
- "What are whales buying right now?"

## Deployment
Deployed on Nosana network via nos_job_def/agent.json
